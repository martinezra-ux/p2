Guia de editar y publicar online

  1. Crear la carpeta en el disco duro, trabajamos en local
  2. Abrimos el programa Visual Studio Code, arrastra la carpeta al explorer o open folder
  3. Crear new file: index.html
  4. Editamos el archivo
  5. Abrimos el navegador y accedemos a nuestro perfil de github
  6. Y crearemos un repositorio como por ejemplo el repositorio p1
  7. Ad file i uplodaded file
  8. Una vez el archivo idex.html aparece en el directorio de nustro respositorio, vamos a settings, en la barra de la izquierda buscamos pages y en github pages cambiamos name a main y apretamos save
  9. Esperamos un poco y actualizamos y nos aparecera nuestra url del respositorio en formato wrpagge
